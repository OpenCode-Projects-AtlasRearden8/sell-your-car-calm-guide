# 06 · All Checklists

Every checklist from the guide, in one place. Print this page (Ctrl+P) and keep it with the car's paperwork folder. Prefer one-page-per-stage? The website version at [`site/checklists.html`](../site/checklists.html) prints each stage on its own page.

## Stage 1 — Pricing (one sitting, ~30 min)

- [ ] Looked up value on KBB, Edmunds, and live local listings (sold listings, not just asking)
- [ ] Honest condition rating chosen — very good / good / fair
- [ ] Ask price, target price, and walk-away price written down
- [ ] My ask price is near the middle of current local listings
- [ ] Car washed, vacuumed, personal items removed
- [ ] Title, registration, maintenance records, spare keys gathered (starts Stage 2)

## Stage 2 — Title & Bill of Sale (one sitting, ~1 hour)

- [ ] Found the physical title
- [ ] Title is in my name — or I've started the fix (duplicate / transfer / probate step)
- [ ] No liens — or I've called the lender for payoff and release
- [ ] Checked title branding (salvage/flood/fleet); disclosed in listing if branded
- [ ] Looked up whether my state requires title notarization
- [ ] Bill of sale drafted — 2 copies ([template](07-templates.md))
- [ ] Registration, owner's manual, maintenance records, both keys in one folder

## Stage 3 — Safe Test Drives (per buyer, ~20 min prep)

- [ ] Public daytime meeting spot chosen (police-station exchange lot if available)
- [ ] Buyer's name and phone number collected
- [ ] Buyer's driver's license copied/photographed before the drive
- [ ] Test-driver coverage confirmed with my insurer
- [ ] Title, wallet, and valuables NOT in the car
- [ ] I drive the first few minutes; a friend joins if possible
- [ ] Buyer never drives the car alone — ever
- [ ] Car re-locked, keys in pocket, flaws pre-disclosed
- [ ] No deposit taken except per Stage 4 rules

## Stage 4 — Payment (sale day)

- [ ] Payment method agreed in advance and vetted
- [ ] Cash counted in front of me, or teller-verified at a bank
- [ ] Cashier's check issued at the bank in front of me — or verified by calling the issuing bank (number looked up by me)
- [ ] **Funds fully cleared/settled before title changes hands**
- [ ] No overpayment / no "refund the difference" accepted — ever
- [ ] Title back and bill of sale signed by both, in ink, copies photographed
- [ ] My plates removed; keys handed over last

## Stage 5 — DMV & Insurer (within 24 hours, ~30 min)

- [ ] State notice-of-sale / release-of-liability form filed
- [ ] Confirmation screenshot or receipt saved in the sale folder
- [ ] Insurer: old car removed (new car added first, if buying)
- [ ] Pro-rated insurance refund confirmed
- [ ] Plates returned or transferred per state rules
- [ ] Toll transponder unlinked; subscriptions/auto-payments cancelled
- [ ] Complete sale folder kept for records

## The 3 rules (memorize, skip the rest)

1. **Slow is safe.** Rushed buyers are scammers. Real buyers wait.
2. **Paperwork before people.** Title confirmed before the car is listed.
3. **Not done until the DMV is told.** Liability ends when your state gets the notice — and not one second before.

## State-specific lookup shortcuts

- Notice of sale / release of liability: search "**[my state] DMV release of liability**"
- Title notarization rules: search "**[my state] title transfer seller signature notary**"
- Bill of sale form: search "**[my state] DMV bill of sale form**"
